# 복사해서 쓰는 프롬프트 모음

중괄호 `{ }` 안만 내 단원과 업무로 바꾸면 됩니다.

## 지시문에 넣을 다섯 가지

역할 + 과업 + 대상 + 맥락 + 산출 형식.
구글이 교사용 가이드에서 PARTS로 정리한 틀입니다.

```
고등학교 과학 교사 입장에서, 7주차 빛의 굴절 수업을 바탕으로
학생용 실험 안내서를 만들어줘. 학습 목표, 준비물, 단계별 지시,
관찰 기록란, 성찰 질문 2~3개를 넣고, 고등학생이 읽을 말투로 써줘.
```

## 수업용

### 수업 설계
```
{7주차 단원}에서 다룬 개념 중 {8주차 단원}을 이해하려면
다시 짚어야 할 것을 골라줘. 8주차 시작 전에 쓸
10분짜리 복습 활동도 같이 만들어줘.
```

### 학습 자료
```
{단원}을 바탕으로 학생용 활동지를 만들어줘.
학습 목표, 준비물, 단계별 지시, 관찰 기록란,
성찰 질문 2~3개를 넣고 {학년} 학생이 읽을 말투로.
```

### 평가 문항
```
{단원}에서 {핵심 개념}에 대한 이해를 확인할 서술형 문항 2개를 만들어줘.
{학년} 수준에 맞추고, 단순 암기가 아니라 생각을 끌어내는 문항으로.
```

### 수준별 자료
```
{단원}으로 세 가지 활동을 만들어줘.
기초, 보통, 심화 세 수준으로 나누고
세 버전 모두에 어휘 도움말을 붙여줘.
```

### 학생이 직접 쓸 때
```
{개념}이 뭔지 잘 모르겠어. 가장 쉬운 말로 설명해줘.
```

## 업무용

### 협의회 브리핑
```
올린 자료를 바탕으로 다음 교과협의회에서 공유할 요약을 만들어줘.
다음 2주 핵심 목표, 진도상 유의점, 함께 논의할 지점을 나눠서 써줘.
A4 한 장 분량으로.
```

### 민원 대비 FAQ
```
학부모가 물어볼 만한 질문 10개와 답을 만들어줘.
답은 자료에 근거한 문장만 쓰고, 자료에 없으면
"확인 후 안내드리겠습니다"로 남겨줘.
```

마지막 줄을 빼면 없는 내용을 그럴듯하게 채웁니다.

### 회의록 정리
```
회의 녹음을 바탕으로 결정 사항, 담당자, 기한을 표로 정리해줘.
발언자 이름은 쓰지 말고 직책으로만 표시해줘.
```

마지막 줄이 개인정보 보호 장치입니다.

### 사실 대조
```
올린 문서들 사이에 같은 항목을 다르게 적은 곳이 있는지 찾아줘.
어느 문서의 몇 쪽인지 함께 알려줘.
```

## 오디오 개요 맞춤 지시

연필 아이콘을 누르고 넣습니다.

```
중학교 2학년이 듣는다고 생각하고 쉬운 말로 해줘.
전문 용어가 나오면 바로 풀어서 설명해줘.
자료에 나온 통계 수치 세 개는 반드시 언급해줘.
마지막에 학생이 스스로 생각해볼 질문 하나를 남겨줘.
```

첫 줄에서 학년을 지정하는 것이 가장 효과가 큽니다.

## 내보내기 전 검수 4줄

1. 인용이 안 붙은 문장을 찾아 지우거나 직접 고쳐 씁니다
2. 숫자는 원문을 열어 눈으로 대조합니다
3. 학생 이름, 학번, 연락처가 섞여 들어갔는지 훑습니다
4. 문장 말투를 내 말투로 두세 군데 고칩니다

4번은 학생부 기재요령이 요구하는 "최종 입력 전 확인"과 연결됩니다.
