# 실습용 공통 예제 파일 — 배포 안내

이 폴더는 수강생 전원에게 나눠주는 실습 자료입니다. 강의 전에 아래 5개 파일을 내려받아 한 폴더에 넣고 압축해 배포하세요.

## 왜 교과서를 안 쓰는가

교과서와 문제집은 저작권 때문에 통째로 업로드해서 실습할 수 없습니다. 저작권법 제25조 제3항은 수업 목적 이용을 "일부분"으로 한정합니다. 그래서 공공누리 제1유형 자료만 골랐습니다. 제1유형은 출처만 밝히면 상업적 이용과 변형까지 허용합니다.

## 형식을 일부러 섞었습니다

| 파일 | 실습에서 하는 일 |
|---|---|
| 1번 PDF | 첫 업로드. 중점과제가 구조화되어 있어 마인드맵이 깔끔하게 나옵니다 |
| 2번 HWPX | **변환 실습**. 한글 파일이 안 올라간다는 걸 직접 겪고 PDF나 DOCX로 바꿔 올립니다 |
| 3번 PDF | 오디오 개요 소재. 그래프와 서술이 섞여 있어 방송 결과물이 가장 잘 나옵니다 |
| 4번 웹 주소 | **URL로 소스 추가** 실습. 2번과 교차 질문해 수치가 맞는지 확인합니다 |
| 5번 CSV | 표 데이터 해석. 데이터 테이블 산출물과 연결합니다 |

2번을 HWPX로 배포하는 것이 의도입니다. 수강생이 직접 막혀봐야 슬라이드 8의 내용이 기억에 남습니다.

## 유튜브 소스 실습에 대해

공공누리 제1유형이면서 자막이 있는 공공기관 영상을 찾지 못했습니다. 교육부 홍보영상은 제4유형(변경 금지)이라 실습에 부적합합니다.

**대안**: 수강생 본인이 스마트폰으로 녹음한 3분짜리 수업 설명이나 회의 발언을 올리게 하세요. 저작권 문제가 없고, "내 수업을 AI가 요약해준다"는 체감이 공공 영상보다 훨씬 큽니다. 오디오 파일은 공식 지원 형식입니다.
