# 아웃라인 — 노트북LM(현 제미나이 노트북)으로 수업과 업무 자동화하기

- 청중: 교사·강사 중심
- 길이: 90~120분 워크숍 (실습 4회)
- 톤: 실습 따라하기 + 캐주얼
- 슬라이드: 본문 41장 + 출처 부록 5장 = 46장
- 실습 방식: **공통 예제 파일 배포** (실습④만 각자 자기 업무)
- 게이트1 승인: 사용자 승인 (실습 방식을 "각자 자료" → "공통 예제 파일"로 수정 후 승인)
- 게이트2 승인: 사용자 승인. 아래 변경분이 반영된 상태 (명칭 병기, 접속 경로 경고, HWP, 산출물 갱신, 공식 프롬프트, 복제 불가, 규범 분할, 한도 갱신, 트러블슈팅 교체)
